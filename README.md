# Timeless SMP

Resource pack for the Timeless SMP Minecraft server (Java Edition 26.3, Season 7).

## Download (latest all-in-one pack)

**[pack.4.zip](https://github.com/weee64253-debug/Timeless-SMP/releases/download/v1/pack.4.zip)**

- SHA-1: `047d94b54ce025c466fd6ce8a4909d2d205c6154`
- Size: 45,335,677 bytes
- Pack format: 97

The server sends this pack automatically when you join, so you normally don't need to download it yourself.

### What's inside
- **29 custom music discs** (TimelessCustomDisc): sounds, textures and item models
- **Frost armour and sword** textures and models
- **Timeless Heisenberg** items (32x32): Cocaine Bag, Cocaine Powder, Shrooms, Weed and Crystal Meth
