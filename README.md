# Timeless SMP

Resource pack and plugin downloads for the Timeless SMP Minecraft server (Java Edition 26.3, Season 7).

## Download (latest all-in-one pack)

**[pack.6.zip](https://github.com/weee64253-debug/Timeless-SMP/releases/download/v1/pack.6.zip)**

- SHA-1: `7c11827407c2221e68c31cfaba049f23d2ed2251`
- Size: 45,337,246 bytes
- Pack format: 97

The server sends this pack automatically when you join, so you normally don't need to download it yourself.

### What's inside
- **29 custom music discs** (TimelessCustomDisc): sounds, textures and item models
- **Frost armour and sword** textures and models
- **Timeless Heisenberg** items (32x32): Cocaine Bag, Cocaine Powder, Shrooms, Crystal Meth, Liquid Meth and Narcan
